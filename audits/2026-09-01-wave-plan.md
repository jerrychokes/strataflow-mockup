# Wave plan — 1 September 2026

Phase 4 of `EXPANSION_BRIEF.md`. Waves are ≤ 8 screens or ≤ 1 week, whichever is
smaller; ordering follows the brief (import → report → obligations → field → figures →
water → configuration; deferred scope last). Every wave ends with `node build.mjs`
green and the §10 sweep green at 375, 1000 and 1280 px, and then the independent audit
loop (§11) before the next wave starts. Sources: the pass-4 findings note and the
extended `#coverage` matrix — a wave item without a matrix row behind it does not
belong here.

measurably overflow and prose that states falsehoods.

**New screen (1):** the format estate — every format the project exchanges,

screen says so where a reader would look for a "send" button.
