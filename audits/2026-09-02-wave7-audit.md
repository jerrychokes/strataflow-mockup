## Findings

### W7-A-1 · P3 — The README dates Wave 7 to 1 September; the wave's own records say 2 September

- **Evidence:** `git log -1 d3630dd` → committed 2026-09-02 00:15 UTC (08:15 AWST, 2 Sep);
  the wave's own deferral comment says "recorded **2 September 2026** (wave 7)"
  (seed.mjs:3115); the README's new section opens "**Wave 7 (1 September 2026)**".
- **Expected:** in a catalogue whose whole method is dated records, the wave's date agrees
  with its own artifacts. **Observed:** two dates for one wave.
- **Correction:** change the README line to 2 September 2026.

### W7-A-2 · P3 — The plate prints the gradient at 1.9; the prose beside it at 1.93

- **Evidence:** plate text "Flow 119° · **1.9 m/km**" vs prose "119° · **1.93 m/km** ·
  0.04 m" (DOM probe, `map-1280.png`). Both read `POTENTIOMETRIC_FIT`, so this is
  rendering precision, not drift — and the README's own claim ("read those three from one
  computation") is accurate. But the catalogue's new rendering rule reasons at length that
  "1.77 in a table beside 1.77 in a sentence is the rule agreeing with itself", and here
  the plate and the sentence disagree at the second significant figure on the same screen.
- **Correction:** render both at the same precision, or state the plate's precision rule
  the way the narrative states its own.

### W7-A-3 · P3 — `PAS-WO-268841` is both the metals batch id and the submission's work order

- **Evidence:** `METALS_BATCH.id = 'PAS-WO-268841'` (seed.mjs:827) — and the subcontract
  chain's first transfer names its physical origin "PAS laboratory — work order
  PAS-WO-268841" (seed.mjs, S1 `transfers[0]`; renders on `#ecoc`). The claim "the chain
  names YAR-B-118420, never the metals batch" holds where it matters — the lineage's batch
  hop names only the PFAS batch, measured — but a laboratory work order covers a
  submission while a batch covers a method run, and one identifier serving as both leaves
  the custody hop nominally citing "the metals batch" as the bottle's origin.
- **Correction:** give the PAS work order its own identifier (or note the conflation where
  the S1 chain renders), so the custody origin and the analytical batch stop sharing a name.
