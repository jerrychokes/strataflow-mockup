## Findings

### W18-A-1 · P2 — The `asks` verbatim check is brief-wide, so a quote attributed to the wrong section passes

- **Evidence / reproduction:** in a scratch worktree, replace §4.2's `asks` in `seed.mjs` with
  §12.1's sentence, verbatim from the brief:

  ```
  'The vendor shall show users constructing queries through combinations of the following dimensions.'
  →
  'The existing Interpretation Editor is strategically strong and must be expanded rather than
   replaced with generic word-processing functionality.'
  ```

  `node build.mjs` **exits 0** and prints `vendor brief: 77 rows closed against
  VENDOR_REQUIREMENTS.md`. Every other mutation in the battery failed the build by name:
  a new `### 4.9` heading → `brief subsections: no row for 4.9`; a renamed heading →
  `brief subsections: no row for 5.31`; a reworded title → `§4.4: title reads "Result
  representations", the brief's heading reads "Result representation"`; a dropped bullet →
  `§5.5: enumerates 8 items in the brief, the row says 9`; a reworded `asks` →
  `row 4.2: its quoted words are not in the brief`; a reworded §17 bullet →
  `§17 screen states #1: row reads … the brief reads "REWORDED …"`; a changed §3 priority →
  `§4: the brief ranks it P2, the enumeration says P0`.
- **Cause:** `build.mjs` checks `flat.includes(norm(r.asks))` against the whole normalised
  brief. It catches a paraphrase — which is what its own comment claims — but not a
  **misattribution**, and a row quoting another section's words reads on `#coverage` as that
  section's own demand.
- **Affected criterion:** the wave's central claim, "the enumeration is closed by the build,
  not asserted", and §19's traceability matrix — a row whose quoted words come from elsewhere
  is precisely a matrix row that has stopped tracing.
- **Expected:** a row's quoted words are found in the section the row claims.
- **Observed:** found anywhere in the document.
- **Recommended correction:** scope the check to the row's own subsection text — the guard
  already slices the file by heading to count bullets, so the span is in hand; assert
  `sectionText(r.id).includes(norm(r.asks))` for requirement rows and keep the flat check as
  the fallback for the four list groups.

  the wave's own account names these two counts as corrections it made to the same document.

  first half stands and the second does not"*), so the remedy is established, not invented.
- **Affected criterion:** not a wave acceptance criterion — hence P2, outside the gate — but a
  traceability defect of the type the whole catalogue is built to refuse.
- **Expected:** a dated correction beside each, in the shape the OM-2 row uses.
- **Observed:** silence, beside a dated correction for a third point in the same file.
- **Recommended correction:** two sentences, dated 3 September 2026, beside lines 64 and 113 —
  the original reading kept, the measured count given, and the build guard named as what now
  holds it.
